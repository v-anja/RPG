**Mini RPG**

A small top-down RPG built in Godot and my first venture into game development.

The game started as a way for me to learn Godot and GDScript and gradually turned into a mini RPG featuring combat, enemies and hopefully NPC interactions, quests, and a boss fight.

I do still need to work on developing the enemy movement - chasing after the player + returning to spawn point - possible features coming soon to repositories near you.
